# Levantamiento

App web para levantamientos de edificaciones en terreno con huincha láser Bosch GLM (Bluetooth).

- Croquis de planta completa: muros de cerramiento, tabiques, puertas, ventanas y vanos.
- Cotas asignadas directamente desde la huincha láser.
- Fotos con flechas de cota y notas.
- Exporta DXF (CAD), PNG, CSV y respaldo.

Abrir en Google Chrome (Android): https://josemiguelsantibanez-maker.github.io/LEVANTAMIENTO/

Los datos de cada levantamiento quedan guardados solo en el teléfono.
